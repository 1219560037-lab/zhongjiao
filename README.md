## 项目核心内容

### 研究对象
- 脚手架支撑架（非外防护架）
- 用于模板支撑，位于梁和楼板下方

### 研究目标
1. 智能布置方案生成：基于200+平面布置图，使用图神经网络自动生成符合规范的脚手架布置方案
2. 多模态大模型应用：输入图纸+工况参数，输出布置方案和施工计算书
3. CAD二次开发：实现自动绘图功能

### 主要研究内容
1. 构建基于知识图谱认知表示的语言及语义模型
2. 设计行动推理融合的混合认知多模态大模型
3. 完善混合认知多模态大模型的智能施工设计辅助系统

### 预期成果
- 智能布置方案自动生成
- CAD自动化绘图
- 自动生成施工计算书
- 可演示的系统原型

## 技术要点

### 约束条件
- 脚手架步距符合规范（60、90、120等标准值）
- 与梁保持合理的几何关系（垂直或斜交）
- 考虑楼板厚度、梁截面等参数影响

### 技术方案
- 图神经网络（GNN）进行方案学习
- 多模态大模型处理图纸和参数
- CAD二次开发实现自动绘图
- 知识图谱辅助推理决策
